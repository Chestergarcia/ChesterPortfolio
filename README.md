# Chester Garcia — Portfolio

A responsive UI/UX and web design portfolio built with React, Vite, and Framer Motion.

## Live site

https://chestergarcia.github.io/ChesterPortfolio/

## Run locally

```bash
npm ci
npm run dev
```

## Build

```bash
npm run build
```

The GitHub Actions workflow deploys the site to GitHub Pages whenever changes are pushed to `main`.

## Contact form

The Request CV button and project cards open a prefilled Gmail compose window addressed to `gchester005@gmail.com`. Gmail must be signed in to send the message; if Gmail is not the computer's default email handler, the link opens Gmail in the browser instead.

The contact form separately submits directly to `gchester005@gmail.com` through FormSubmit. On first use, submit the form and confirm the activation email from FormSubmit before submissions can be delivered to the inbox.
